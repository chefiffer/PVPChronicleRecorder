# PVP Chronicle Recorder · OBS 設定ガイド

このガイドでは、PvP 試合を自動録画するための OBS 設定と、接続失敗、誤ったウィンドウの取得、黒帯、巨大なファイル、不要なデスクトップ音声への対処を説明します。

> [!IMPORTANT]
> Recorder は OBS の制御とローカル録画の関連付けだけを行います。PVP Chronicle、PVP Chronicle Recorder、OBS Studio を先にインストールして有効化してください。

## 1. OBS WebSocket を有効にする

1. OBS を起動します。
2. **ツール → WebSocket サーバー設定**を開きます。
3. WebSocket サーバーを有効にします。
4. 既定ポート `4455` のまま、この PC 専用のパスワードを設定します。
5. 保存し、OBS を起動したままにします。

4455 番ポートをインターネットへ転送したり、他の PC に向けてファイアウォールを開放しないでください。同じ PC 上ではループバックアドレスだけを使います。

ゲーム内で `/pvprec` を入力し、次を設定します。

```text
OBS WebSocket アドレス：ws://127.0.0.1:4455
OBS WebSocket パスワード：OBS で設定したもの
```

「設定を保存」後に「OBS 接続をテスト」を押します。「OBS WebSocket に接続しました」と表示されれば正常です。

## 2. 録画専用シーンを作る

配信用のカメラ、ブラウザー、通知を含めないよう、「FFXIV PvP 録画」などの専用シーンを作成します。

### 方法 A：ゲームキャプチャ

1. ソースの `+` から「ゲームキャプチャ」を追加します。
2. モードを「特定のウィンドウをキャプチャ」にします。
3. `ffxiv_dx11.exe` の「FINAL FANTASY XIV」ウィンドウを選びます。
4. プレビューを確認します。

誤ったウィンドウへ何度も固定される場合は、自動一致に頼らずソースを作り直すか、画面キャプチャを使用します。

### 方法 B：画面キャプチャ

画面キャプチャは安定しますが、そのディスプレイ上のすべてを録画します。FFXIV の画面を選び、実際のゲーム領域までクロップしてください。

## 3. 縦横比を保ったまま黒帯を除く

`px` はピクセルです。`1920×1080` のキャンバス下部に `120 px` の黒帯がある場合、有効高さは次のとおりです。

```text
1080 - 120 = 960 px
```

有効画像は `1920×960` です。

1. OBS でゲームまたは画面ソースを選びます。
2. 右クリックして **変換 → 変換の編集**を開きます。
3. 「クロップ：下」に `120` を入力します。
4. **設定 → 映像**を開きます。
5. 基本（キャンバス）解像度を `1920×960` にします。
6. 出力（スケーリング）解像度も `1920×960`、または同じ比率の低解像度にします。
7. ソースへ戻り **変換 → 画面に合わせる**を選びます。

`Alt` を押しながら端をドラッグしてもクロップできますが、数値入力の方が再現しやすくなります。「画面に引き伸ばす」は人物やマップを変形させるため使わないでください。キャンバス外の黒い領域は録画されませんが、キャンバス内の黒帯は録画されます。5～10 秒のテストファイルを必ず確認してください。

## 4. ゲーム音声だけを録音する

1. **設定 → 音声**を開きます。
2. デスクトップ音声、デスクトップ音声 2、不要なマイクを無効にします。
3. ソースの `+` から「アプリケーション音声キャプチャ（ベータ）」を追加します。
4. `ffxiv_dx11.exe` の FFXIV ウィンドウを選びます。
5. ゲーム音とブラウザー音を同時に再生して確認します。

ゲーム音声メーターだけが動き、ブラウザー、Discord、通知、マイクが録音されなければ正常です。クラッシュ後は旧プロセスが消えます。音声が復帰しなければ新しい FFXIV ウィンドウを選び直してください。

## 5. 録画形式と容量を設定する

| 項目 | 推奨値 | 理由 |
| --- | --- | --- |
| 録画形式 | MKV | OBS やゲーム異常時に MP4 より全損しにくい |
| 映像エンコーダー | 利用可能なら NVENC H.264 | CPU 負荷を抑え互換性が高い |
| 録画品質 | 高品質、中程度のファイルサイズ | リプレイ向けで可逆録画は不要 |
| 音声ビットレート | 128 または 160 Kbps | ゲーム音声に十分 |
| フレームレート | 30 FPS | リプレイに十分で容量を抑えられる |

映像 6000 Kbps、音声 160 Kbps では 1 分あたり約 46 MB です。小さくするには、映像を 3500～5000 Kbps に下げる、詳細出力の CQP を `CQ 24` から試す（値が大きいほど小さく低画質）、30 FPS を維持する、黒帯を含めない、といった方法があります。変更ごとに戦闘を含む 1 分の動画を録り、容量と文字の鮮明さを確認してください。

## 6. Recorder を設定する

ゲーム内で `/pvprec` を入力します。

1. 自動または希望する表示言語を選びます。
2. 対応 PvP 試合の自動録画を有効にします。
3. OBS WebSocket アドレスに `ws://127.0.0.1:4455` を入力します。
4. OBS で設定したパスワードを入力します。
5. Flyleaf FFmpeg フォルダーは通常空欄にし、インストールボタンを使います。
6. 先頭フレーム補正はまず `0 ms` のままにします。
7. 保存して OBS 接続をテストします。
8. 公式 Flyleaf 再生ランタイムをインストールします。
9. ダウンロード、SHA-256 検証、展開の完了を待ちます。

先頭フレーム補正は動画と試合時間軸の一定のずれを修正します。同じ方向・同じ量のずれが複数回再現しない限り `0 ms` のままにしてください。4 つの主要設定には、空欄でも用途が分かるよう名前と説明が表示されます。

画質選択は現在のデコードフレームを縮小するだけで、別動画の変換や作成はしません。C ドライブに代理動画キャッシュは残りません。画面を閉じるとメモリ上のフレームは解放され、OBS 原本と FFmpeg ランタイムは保持されます。

## 7. クラッシュと再接続

クラッシュ前後の動画は自動結合しません。

- 正常終了：終了イベントを受信し、OBS を停止して動画を関連付けます。
- ゲームクラッシュ：終了イベントが欠け、OBS と復旧情報が一致しない場合があります。
- 同じ試合へ再接続：録画再開は保証されず、動画も結合されません。
- 次の試合：新しい独立した録画を作成します。

クラッシュ後は OBS が録画中か確認し、ログイン画面を録っている場合は手動停止してください。必要な元動画は削除しないでください。

## セキュリティとプライバシー

- OBS WebSocket ポートをインターネットへ公開しないでください。
- パスワードをスクリーンショット、Issue、ログへ載せないでください。
- 録画にはキャラクター名、チャット、通知、デスクトップ情報が含まれる場合があります。共有前に確認・編集してください。
- Recorder は録画をアップロードしません。手動でクラウドや GitHub に送ったファイルはプラグインの管理外です。
